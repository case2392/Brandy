# Design Handoff #2 — Letter Practice Day Pages (A–Z)

For Claude Design. This extends the design system you already built for this
repo — match the existing printables exactly (the "Case Family Homeschool"
header with sun motif, the serif display type, the accent-color page pills,
green start dots on traceable letters). Your source files live in
`materials/Letter Pages and Activity Sheets.zip`; the original design brief
is `materials/DESIGN-HANDOFF.md`.

## What to build

**One new PDF: 26 pages, one per letter A–Z, US Letter portrait.**

Purpose: a *second* worksheet for each letter, used later in the week. The
existing "Letter Pages and Activity Sheets.pdf" is Monday's introduction
sheet; this is Thursday's practice sheet. Same letter, same design family,
**different activities** — so the week reinforces without repeating.

A rough content prototype (correct activities, unstyled) is at
`materials/first-drafts/practice-day-pages-A-Z-draft.pdf` — treat it as the
content spec, not a visual reference.

## Page content (each letter, e.g. A)

1. **Header** — same system as the existing letter pages, with a page-type
   pill reading "Practice Day". Name line.
2. **Rainbow trace** — the letter pair (A a) large (~130pt), hollow outline
   only, with start dots. Parent instruction: "Trace the big letters again
   and again with 3 different colors." Interiors must stay white.
3. **Big/little matching** — three uppercase letters in a left column (the
   target letter plus two visually distinct distractors), their lowercase
   forms shuffled in a right column, with connector dots. Child draws lines.
   The target letter must always be included; pick distractors that don't
   look alike (avoid pairing e.g. C/G, M/W, b/d in the same trio).
4. **Letter-grid hunt** — a grid (about 6×3) of mixed letters, upper and
   lower case; 4–6 cells contain the target letter (both cases), the rest
   are distractors. Instruction: "Color every box that has A or a inside."
   Boxes need enough white space to color.

## Constraints (same as the original brief)

- Home-inkjet friendly; legible in grayscale; colorable areas white
- Audience is a pre-reader — instructions are read aloud by the parent
- Template-generated across all 26 letters, not hand-laid-out
- Single-story `a` and simple `g` letterforms for anything traceable,
  matching the letterforms you used in the existing tracing pages
