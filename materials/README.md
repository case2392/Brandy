# Materials

Homemade printables for homeschool. Everything here is generated by
`scripts/generate_printables.py` — ask Claude to tweak and regenerate
(different colors, different stories, more pages, etc.).

## What's here

| File | What it is |
|---|---|
| `letter-of-the-week/big-kid-tracing-pages-A-Z.pdf` | 26 pages, one per letter, for the almost-5-year-old: display letters, guided tracing rows (uppercase + lowercase), a letter hunt, and a draw-it box |
| `letter-of-the-week/toddler-pages-A-Z.pdf` | 26 matching pages for the almost-3-year-old: one giant hollow letter to color / sticker / finger-trace, plus a crayon-trace row |
| `weekly-rhythm-chart.pdf` | One-page chart: the daily rhythm (6 blocks, ~45 min total seat work) plus a focus-of-the-day column with the enrichment school day marked |
| `bible-stories/bible-story-activity-sheets.pdf` | 4 stories x 2 levels (8 pages): Creation, Noah, Jonah, The Lost Sheep. Each big-kid page has the story, a memory verse, talk-about questions, and an activity; each toddler page is a big color/craft version of the same story |

## How they pair up

Print the big-kid page and the toddler page for the same letter/story and do
them side by side at the table — same theme, two depths (see
`../ideas/tag-along-activities-for-an-almost-3-year-old.md`).

## Printing notes

- Standard US letter, portrait (rhythm chart is landscape)
- The toddler letter pages and Bible coloring pages work great with
  do-a-dot markers, stickers, cotton balls, and tissue paper
- The Lost Sheep toddler page is designed for the classic cotton-ball sheep craft
