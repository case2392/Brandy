# Materials

Printables for homeschool. The current set was designed by Claude Design
(from `DESIGN-HANDOFF.md`) — these are the ones to print.

## Current printables (Claude Design versions)

| File | What it is |
|---|---|
| `Letter Pages and Activity Sheets.pdf` | 26 letter-of-the-week pages for Olivia (almost 5): display letters, guided tracing with start dots, letter hunt, draw-it box |
| `Letter Pages and Activity Sheets - Small Kid.pdf` | 26 matching toddler pages (almost 3): giant hollow letter to color/sticker/finger-trace + crayon-trace row |
| `Our Weekly Rhythm.pdf` | One-page daily rhythm chart; Tuesday marked as enrichment school day (9–12) |
| `Bible Story Time.pdf` | 8 pages: Creation, Noah, Jonah, The Lost Sheep — big-kid + toddler versions of each |
| `Letter Pages and Activity Sheets.zip` | Claude Design's HTML source files for the designs above (for future edits in Claude Design) |

## Older files

- `first-drafts/` — the original script-generated versions, superseded by the
  designs above
- `scripts/generate_printables.py` — generator for the first drafts; still
  useful for quickly producing *new* content (more Bible stories, number
  pages) that can then go through Claude Design
- `DESIGN-HANDOFF.md` — the design brief the current versions were built from

## How they pair up

Print the big-kid page and the Small Kid page for the same letter/story and
run them side by side at the table — same theme, two depths (see
`../ideas/tag-along-activities-for-an-almost-3-year-old.md`).

## Printing notes

- US Letter; rhythm chart is landscape, everything else portrait
- Toddler pages work great with do-a-dot markers, stickers, cotton balls
- The Lost Sheep toddler page is designed for the cotton-ball sheep craft
