# Brandy's Homeschool Planning Hub

This repo is the home base for Brandy's homeschool planning — a place to collect
thoughts, research curriculum options, plan weeks, and build materials as we go.

## Our starting point (Fall 2026)

- Oldest daughter is 4½ (almost 5) — starting gentle homeschool this year
- Two younger siblings at home
- She'll attend a homeschool-enrichment program **one day a week for 3 hours**
  (mostly for time with other kids)
- Everything else happens at home with Mom

## How this repo is organized

| Folder | What goes there |
|---|---|
| `curriculum-research/` | Research and comparisons of curriculum options |
| `planning/` | Goals, open questions, yearly/weekly plans |
| `ideas/` | Activity ideas, unit study sparks, things to try |
| `materials/` | Printables and materials we create ourselves |

## How to use it

Brandy: brain-dump freely. Drop thoughts into any file (or a new one) and ask
Claude to organize, research, or build from them. Nothing here needs to be
polished — this is a working notebook, not a publication.
